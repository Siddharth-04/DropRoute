# DropRoute

DropRoute is a programmable file delivery platform that enables secure file sharing through configurable delivery policies.

## Features (Planned)

- Secure file uploads
- Configurable delivery routes
- Policy-based access control
- Delivery tracking
- Audit events

## Tech Stack

### Backend
- Java 21
- Spring Boot
- PostgreSQL
- Flyway
- Spring Security

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
